# Post-event publication checklist

- [ ] Dates, attendance and participation status are accurate.
- [ ] Challenge names and descriptions are verified against the actual event.
- [ ] All findings come from my authorised work and are appropriately attributed.
- [ ] Event is over and writeup disclosure is permitted by organisers.
- [ ] No live flags, private files, credentials, secrets or identifying information are disclosed.
- [ ] Screenshots and logs are reviewed and redacted if needed.
- [ ] Technical commands and claims are tested or explicitly qualified.
- [ ] Scores, awards and rankings are reported only if officially confirmed.
- [ ] README challenge table and relative links work.
- [ ] Lessons learned and defensive relevance are explained clearly.

## Methodology

1. **Understand the objective:** Read the challenge description, identify available artefacts and verify the rules of engagement.
2. **Enumerate the evidence:** Document relevant files, services, clues or outputs that the challenge provides.
3. **Develop hypotheses:** Record plausible explanations before selecting the next investigative step.
4. **Test within scope:** Use authorised tools and techniques, noting commands or queries only when appropriate to disclose.
5. **Validate:** Check whether the evidence supports the result; note limitations and alternate interpretations.
6. **Document:** Record the reasoning chain, timestamps, results and lessons without exposing restricted material.
7. **Reflect:** Explain defensive significance and what I would improve next time.
